## 🎉 What's New

### 新增功能

#### 1. 全文章列表頁面 (all-articles.html)
全新的文章瀏覽體驗，讓訪客能夠一覽所有發布的文章。

**主要特性：**
- 📚 以網格方式展示所有文章
- 🔍 分類篩選（全部/技術/教學/生活）
- 🔄 智能排序（最新/最舊/標題）
- 🎨 精美的卡片設計
- 📱 完美的響應式佈局

#### 2. 單篇文章詳情頁面 (article.html)
為每篇文章提供專屬的閱讀頁面，提升閱讀體驗。

**主要特性：**
- 📖 完整的文章內容展示
- ↩️ 便捷的返回導航
- 🔗 社交媒體分享功能
- 📋 一鍵複製連結
- 🎯 SEO 優化

#### 3. 首頁優化
首頁現在只展示最新的 6 篇文章，讓訪客快速了解最新動態。

**改進點：**
- 🎯 聚焦最新內容（限制顯示6篇）
- 🖱️ 雙重訪問方式（Modal + 頁面跳轉）
- ✨ 標題懸停效果增強
- 🔗 導航欄直接連結到全文章頁面

## 📖 使用指南

### 訪客使用

#### 瀏覽所有文章
1. 點擊導航欄的「部落格」
2. 在全文章頁面瀏覽所有內容
3. 使用篩選器按分類查看
4. 使用排序功能調整順序

#### 閱讀文章
**方式 1：快速預覽**
- 點擊文章卡片主體
- 在彈出的 Modal 中查看
- 點擊「查看完整文章」進入詳情頁

**方式 2：完整閱讀**
- 直接點擊文章標題
- 進入專屬文章頁面
- 享受完整的閱讀體驗

#### 分享文章
1. 進入文章詳情頁面
2. 滾動到頁面底部
3. 選擇分享平台（Twitter/Facebook/LinkedIn）
4. 或點擊「複製連結」直接複製 URL

## 🔧 開發者資訊

### API 端點
```javascript
GET /api/articles          // 獲取所有文章
GET /api/articles/:id      // 獲取單篇文章
```

### URL 參數
```
article.html?id=1         // 訪問 ID 為 1 的文章
```

### 配置選項
```javascript
// 首頁顯示的最大文章數
const MAX_HOME_ARTICLES = 6;

// API 端點
const API_URL = "http://localhost:3000/api";
```
